# Ender-5-Plus-drut

Personal configuration of Ender 5 plus. I wanted to kinda resurect the machine since configuration firmware and board from creality are outdated and not supported.
## Features

- SKR mini E3 v3 32Bit 
- TFT35 V3.0.1  
- BTT Relay 1.2  
- MicroSwiss NG Revo
- Creality CR-touch


## Files

Pre-compiled file of firmware for board

```bash
  firmware.bin
```

Configuration files for compilation Marlin-bugfix-2.1.x

```bash
  Marlin-bugfix-2.1.x/*
```

This folder contains images that i used to help myself to connect everything

```bash
  Images/*
```
